¿Qué quieres hacer?

Al abrir LAB, primero inicia sesión o crea tu cuenta. Si entraste mediante una invitación temporal de 24 horas, el acceso de invitado omite esa pantalla. Después elige el camino según tu objetivo.

RUTAS PRINCIPALES
PRIMERO · ACCESO
CUENTA PERSONAL → INICIAR SESIÓN / CREAR CUENTA. INVITACIÓN 24 H → ACCESO DE INVITADO.
JUGAR Y LLEVAR SCORES
REGISTRO DE JUGADORES → OK → CONFIRMACIÓN → INICIAR RONDA → anotar scores manualmente.
SEGUIR UN TORNEO
TORNEOS → elegir torneo → GENERAL / CATEGORÍAS / BUSCAR POR NOMBRE / ARMAR MI TABLERO.
SEGUIR VARIOS TORNEOS O GRUPOS
Añade jugadores o grupos a MI TABLERO. El tablero conserva lo elegido y se actualiza aunque estés viendo otro torneo.
DÓNDE ESTOYTras resolver el acceso personal o de invitado.
QUÉ QUIERO HACERJugar o seguir uno o varios torneos.
QUÉ BOTÓN TOCOREGISTRO DE JUGADORES para jugar; TORNEOS para seguimiento LIVE.
CÓMO REGRESOUsa ATRÁS para volver al nivel anterior sin perder tu tablero.
