Monitor de Tiempo · pantalla actual

ÍNDICE
MONITOR DE TIEMPO ACTUAL. INICIO registra la hora de comienzo. FINAL registra la hora de terminación. TIMER muestra el tiempo transcurrido. RESET reinicia únicamente el monitor de tiempo. Los cuatro controles deben permanecer visibles, separados y sin cubrir la Score Card.
← ANTERIORÍNDICESIGUIENTE →
24A

MONITOR DE TIEMPO · pantalla vigente

ÍNDICE

Controles actuales

INICIO
Muestra la hora de inicio de la ronda activa.
FINAL
Muestra la hora de cierre cuando la ronda termina; antes del cierre aparece —.
TIMER
Muestra el tiempo transcurrido en formato HH:MM:SS. Tocar el bloque TIMER pausa el conteo; tocarlo de nuevo lo reanuda. El tiempo pausado no se suma al total.
RESET
Pide confirmación antes de reiniciar el cronómetro a 00:00:00. Conserva jugadores y scores de la ronda.

Importante: el antiguo control independiente para detener el cronómetro ya no es un control visible. La interacción vigente se hace desde el bloque TIMER; el cierre de ronda actualiza FINAL.
