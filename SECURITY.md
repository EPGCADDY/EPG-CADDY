# Política de seguridad

## Versiones admitidas

Sólo la versión identificada como Producción en la matriz Gate 0 recibe soporte. Las ramas Preview son candidatas no comerciales.

## Reporte responsable

No publique vulnerabilidades como un issue abierto. Use **Security → Report a vulnerability** en el repositorio GitHub de EPGCADDY/EPG-CADDY e incluya versión, impacto, reproducción segura y evidencia sin datos personales reales.

## Respuesta

El equipo clasificará el caso según `docs/operations/INCIDENT_RESPONSE.md`. Esta política no promete una recompensa ni sustituye acuerdos escritos. No se autorizan interrupciones del servicio, extracción de datos, ingeniería social ni pruebas contra terceros.
