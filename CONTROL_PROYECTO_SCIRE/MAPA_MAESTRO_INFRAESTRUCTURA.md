## Puertas de la aplicación

| Dirección | Archivo | Para qué sirve |
|---|---|---|
| `/api/account` | `api/account.js` | Crea, abre o cierra la cuenta opcional. |
| `/api/backup` | `api/backup.js` | Guarda o recupera un respaldo. |
| `/api/database-health` | `api/database-health.js` | Atiende una función de la aplicación. |
| `/api/score` | `api/score.js` | Recibe resultados. |
| `/api/session-grupal` | `api/session-grupal.js` | Atiende una función de la aplicación. |
| `/api/session` | `api/session.js` | Abre el servicio de voz anterior. |
| `/api/sync` | `api/sync.js` | Envía y recibe cambios entre el teléfono y el respaldo. |

## Información central

| Nombre exacto | Qué guarda |
|---|---|
| `players` | Jugadores principales. |
| `player_contacts` | Teléfonos y otros medios de contacto. |
| `consent_events` | Permisos dados o retirados por cada jugador. |
| `rounds` | Rondas jugadas. |
| `round_players` | Jugadores incluidos en cada ronda. |
| `hole_scores` | Golpes y resultados por hoyo. |
| `card_artifacts` | Tarjetas creadas para entregar. |
| `deliveries` | Entregas realizadas. |
| `sync_mutations` | Cambios enviados desde los teléfonos. |
| `player_profile_events` | Historial de cambios de cada jugador. |
| `installations` | Instalaciones reconocidas de la app. |
| `golf_courses` | Campos de golf. |
| `course_definition_events` | Cambios hechos a la información de los campos. |
| `tournaments` | Torneos registrados. |
| `player_handicap_events` | Historial de hándicap. |
| `player_tee_events` | Historial de marcas de salida. |
| `player_contact_events` | Historial de contacto. |
| `round_snapshots` | Copias exactas de una ronda en distintos momentos. |
| `round_lifecycle_events` | Inicio, cierre y cambios importantes de una ronda. |
| `score_events` | Historial de cada resultado registrado o corregido. |
| `card_records` | Registro de tarjetas oficiales. |
| `share_events` | Registro de tarjetas compartidas. |

## Llaves y direcciones privadas necesarias

El mapa sólo guarda los nombres; nunca guarda contraseñas ni valores secretos.

| Nombre exacto | Para qué sirve |
|---|---|
| `DATABASE_URL` | Dirección privada de la base central. |
| `SYNC_API_TOKEN` | Llave privada para aceptar sincronizaciones. |
| `NEON_AUTH_URL` | Dirección del inicio de sesión opcional. |
| `OPENAI_API_KEY` | Llave privada del servicio de voz. |
| `GSC_MOBILE_API_ORIGIN` | Dirección que usan las apps Apple y Android para comunicarse. |
| `GSC_REVENUECAT_IOS_PUBLIC_KEY` | Llave pública de compras para Apple. |
| `GSC_REVENUECAT_ANDROID_PUBLIC_KEY` | Llave pública de compras para Android. |
| `NODE_ENV` | Indica si la aplicación está en producción. |

## Regla permanente

1. Todo nombre visible será **Golf Score Card GT**.
2. Los códigos antiguos sólo se conservan cuando cambiarlos rompería algo.
3. Nunca se publican contraseñas, correos personales o llaves privadas.
4. Este mapa se actualiza cuando se agrega, retira o cambia una pieza importante.
