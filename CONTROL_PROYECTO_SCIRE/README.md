# Control de proyecto · SCIRE CARD GUATEMALA

Este directorio es el mapa operativo obligatorio del proyecto. Se consulta al cerrar cada caso para continuar con el siguiente pendiente sin solicitar nuevamente directrices ni documentos ya entregados.

## Regla de operación

1. Las directrices del propietario se registran y no se vuelven a pedir.
2. Las fotografías originales permanecen intactas y separadas de capturas de la aplicación, reconstrucciones y archivos generados.
3. Cada fuente original se archiva por campo con nombre legible y un identificador estable.
4. Los reenvíos idénticos se conservan como evidencia, pero nunca sustituyen la fuente maestra.
5. Al concluir un caso se revisa automáticamente la cola de pendientes.

## Secciones

- `01_DIRECTRICES_PEDIDOS_Y_ORDENES_PENDIENTES`: reglas mandatorias y cola vigente.
- `02_DOCUMENTOS_IMPORTANTES_PENDIENTES_DE_UTILIZAR`: material recibido que todavía debe incorporarse al producto.
- `03_CASOS_TERMINADOS_Y_EVIDENCIA`: cierres técnicos, pruebas y aprobaciones.
- `04_MATRIZ_DE_CAMPOS`: inventario de fuentes originales por campo.
- `05_MATRIZ_DE_ENLACES`: separación obligatoria entre las rutas General y Stableford.
