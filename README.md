# Objetivo

EPG Caddy es un sistema profesional de inteligencia artificial diseñado para asistir al golfista durante toda la ronda mediante interacción por voz, análisis estratégico, registro automático de estadísticas y generación de recomendaciones.

El objetivo del proyecto es desarrollar una aplicación comercial de clase mundial para iPhone y Android.

# Principios de Desarrollo

Todo cambio del proyecto deberá cumplir las siguientes reglas:

1. Ninguna decisión dependerá del historial de conversaciones.
2. Toda regla aprobada deberá documentarse en GitHub.
3. La documentación será la fuente oficial del proyecto.
4. El código deberá implementarse respetando la documentación.
5. Cada componente tendrá una única responsabilidad.
